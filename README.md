# RiceHack

A Streamlit operations dashboard with mock analytics charts (signups, active users, revenue, conversion rate, channel mix, regional activity, and campaign efficiency).

## Project structure

```
paddydash/
├── app.py             # Streamlit dashboard app
└── requirements.txt   # Python dependencies
```

## Getting started

```bash
cd paddydash
pip install -r requirements.txt
streamlit run app.py
```
