# Milestone July 28: Data Inspection Notes
**Author:** Đức Anh (Data Analyst)

Based on the 6 datasets uploaded to Google Drive:
1. `core-poi-geometry-rice`: Contains `PLACEKEY`, `LATITUDE`, `LONGITUDE`, `POLYGON_WKT`, `TOP_CATEGORY`.
2. `daily-spend-brand-and-state-rice`: Contains `SPEND_AMOUNT`, `TRANS_DATE`, `MARKET`, `BRAND_NAME`, `TRANS_COUNT`.
3. `daily-weather-rice`: Contains `DATE`, `MAXIMUM_TEMPERATURE_C`, `PRECIPITATION_MM`, `MARKET`.
4. `spend-patterns-rice`: Contains demographic and income segments.
5. `store-visits-rice`: Contains `PLACEKEY`, `DATE`, `RAW_VISIT_COUNTS`, `MEDIAN_DWELL`.
6. `urban-heat-index-rice`: Contains `PLACEKEY`, `URBAN_HEAT_INDEX`.
