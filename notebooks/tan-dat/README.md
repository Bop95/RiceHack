# Tan Dat Notebook Workspace

Role: Weather analysis and SerpAPI support.

Assigned dataset:

- `daily-weather-rice`

Expected outputs:

- cleaned weather tables;
- invalid and sentinel-value checks;
- summaries for temperature, precipitation, humidity, wind, visibility, and pressure;
- weather-risk indicators;
- weather visualizations;
- compact FinalFlow weather integration table;
- notes for future SerpAPI and search-source display behavior.

Collaboration dependencies:

- Duc Anh for shared export conventions.
- Hai Nam for source display testing and future AI interface behavior.
- Phuong Anh for weather context in business recommendations.

Suggested filenames:

- `weather_initial_audit.ipynb`
- `weather_risk_indicators.ipynb`
- `weather_summary_exports.ipynb`

Do not commit:

- raw `daily-weather-rice` files;
- SerpAPI keys or other secrets;
- web search result dumps containing restricted or unnecessary data;
- large generated exports.
